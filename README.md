# SIH26165 - SIF Intelligence

AI-powered safety intelligence platform for detecting Serious Injury and Fatality (SIF) precursors from industrial safety reports.

## Team

SIH 2026 Team Project

## Status

🚧 Under Development

## Tech Stack

- Next.js + TypeScript
- FastAPI + Python
- PostgreSQL + pgvector
- NLP / LLM-based extraction
- React Flow + Recharts

## Goal

Turn unstructured safety reports into explainable, actionable safety intelligence using SIF risk analysis, causal graphs, similar incident search, and barrier-failure insights.
